4 스마트필터 12개
필터 점수화 시스템

각 필터는 긍정(+1), 부정(-1), 중립(0)으로 점수화되어 합산됩니다.

방향필터점수
긍정 MA 정배열 +1
긍정 거래량 증가 (2배 이상) +1
긍정 MA60선 위 (60일 이동평균 위) +1
긍정 스퀴즈 진입 (BB 수축, 에너지 축적) +1
긍정 눌림목 (50점 이상, 반등 포인트) +1
긍정 RSI 과매도 (≤30, 바닥권) +1
긍정 MACD↑ (히스토그램 음→양 전환) +1
부정 MA 역배열 -1
부정 거래량 감소 (0.3배 이하) -1
부정 RSI 과매수 (≥70, 과열) -1
부정 MACD↓ (히스토그램 양→음 전환) -1
중립 스퀴즈 해제 (BB 확장 시작) 0
알림 발동 조건

필터가 최소 2개 이상 감지되어야 하며, 신호별 합산 조건을 충족해야 합니다.

신호조건예시
BUY 합산 ≥ +2 정배열(+1) + MA60↑(+1) = +2 ✓
SELL 합산 ≤ -2 역배열(-1) + MACD↓(-1) = -2 ✓
HOLD |합산| ≥ 3 정배열(+1) + MA60↑(+1) + RSI과매도(+1) = +3 ✓

BUY + 부정 필터만 → 알림 안 함 (오판 방지)
SELL + 긍정 필터만 → 알림 안 함
HOLD는 더 엄격 (|합산| 3 이상 필요)

🎯 추천기 스마트필터는 AND(모두 충족), 워치리스트는 점수화 OR(합산 기준) — 워치리스트가 더 빠르게 알림을 줍니다.

6 알림 주기 갱신 방식

워치리스트 알림은 주기 단위로 갱신됩니다. 쌓이지 않습니다.

매 스캔 주기마다:
① 모든 종목을 순서대로 분석
② 조건 충족 → 🚨 표시 + 알림 발송
③ 조건 미충족 → 🚨 해제
④ 다음 주기에 다시 재평가

사용자가 확인하지 않아도 다음 주기에서 자동으로 리셋됩니다. "지금 현재" 조건을 충족하는 종목만 알림 표시됩니다.

7 분석기 연동
종목 탭 → 분석기 이동

워치리스트에서 종목을 탭하면 즉시 분석기 탭으로 이동합니다.

종목명 + 등록된 TF가 자동 세팅되어 바로 상세 분석할 수 있습니다.

독립 동작

워치리스트 스캔은 분석기와 독립적으로 작동합니다. 분석기에서 다른 종목을 분석하는 중에도 워치리스트 스캔은 정상 실행됩니다.

10 자주 묻는 질문

다른 탭에 있어도 알림이 오나요?

네, ORACLE 탭이 브라우저에서 활성 상태이면 어떤 탭(추천기/분석기/감독관)에 있어도 토스트+진동이 옵니다. Lv2 이상이면 워치리스트 탭에 펄스가 표시됩니다.

점수는 높은데 HOLD인 이유는?

BUY/SELL 판정에는 점수 외에도 여러 안전 필터(momOsc, 변동성, 저항선, 다이버전스 등)가 작동합니다. 79점이어도 안전 필터에서 "아직 확실하지 않다"고 판단하면 HOLD가 됩니다. 이는 오판 방지를 위한 정상 동작입니다.

다른 앱으로 전환하면요?

모바일에서 다른 앱으로 전환하면 백그라운드 제한으로 스캔이 지연됩니다. 화면 분할 모드에서는 정상 작동합니다.

종목을 삭제하면 스캔에서 바로 빠지나요?

네, ✕ 버튼으로 즉시 삭제됩니다. 다음 스캔에서 해당 종목은 제외됩니다.

같은 종목을 다른 TF로 등록할 수 있나요?

아니요, 종목당 1개만 등록됩니다. TF를 변경하려면 삭제 후 원하는 TF로 다시 분석하고 재등록하세요.

알림이 안 뜹니다.

필터가 2개 미만이거나 합산 점수가 조건 미달이면 알림이 안 뜹니다. 예: BUY인데 긍정 필터 1개 + 부정 필터 1개 = 합산 0 → 알림 안 뜸. 이는 오판 방지를 위한 정상 동작입니다.

API 제한에 걸리나요?

코인은 Binance/Upbit, 주식은 Yahoo Finance를 사용하므로 한투 API 제한과 무관합니다. 종목 간 0.8초 간격을 두어 안전합니다.
