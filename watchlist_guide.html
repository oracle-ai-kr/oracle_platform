관심 종목 자동 감시 · 스마트필터 알림 시스템

0 어떻게 작동하나요?

관심 종목을 등록하면, 설정한 주기(5~30분)마다 자동으로 분석을 실행합니다.

BUY/SELL 시그널이 감지되면 토스트 알림 · 진동 · 화면 펄스로 즉시 알려줍니다.

1 종목 등록하기
코인 분석기

검색 필드에 코인명(BTC, 비트코인) 입력 또는 ▼ 버튼으로 전체 목록 탐색.

Upbit KRW 마켓 전체가 자동 로드됩니다.

주식/ETF 분석기

분석기 탭에서 선택한 구역(코스피/코스닥/ETF/S&P500 등)을 워치리스트가 자동으로 따라갑니다.

분석기에서 구역을 바꾸면 워치리스트 검색도 해당 구역만 표시됩니다.

💡 최대 30개까지 등록 가능. 이미 등록된 종목은 "등록됨"으로 표시되어 중복 등록을 방지합니다.

3 스마트필터 감지 원리
BUY 시그널 발생 조건

quickScore가 BUY 판정을 내리면, 추가로 3가지 스마트필터 중 2가지 이상을 통과해야 알림이 발송됩니다.

✓ MA 정배열 또는 MA60 위
✓ RSI 70 미만 (과매수 아님)
✓ MACD 히스토그램 양전

→ 3가지 중 2가지 이상 충족해야 BUY 알림 발송. 1가지 미달은 허용, 2가지 이상 미달이면 차단.

SELL 시그널

SELL은 필터 없이 즉시 알림됩니다. 위험 신호는 놓치면 안 되기 때문입니다.

태그 표시 예시

스캔 결과마다 각 종목의 현재 상태가 태그로 표시됩니다.

정배열 MA60↑ RSI 42 MACD양전 거래량 1.3x
역배열 MA60↓ RSI 72 MACD음전 스퀴즈
4 알림 방식 (3종 세트)
① 토스트 알림

화면 하단에 텍스트 알림이 표시됩니다.

📢 BTC → BUY
② 진동

모바일에서 시그널 감지 시 진동 패턴(200ms × 3회)으로 알려줍니다.

패턴: 200ms-100ms-200ms-100ms-200ms

③ 화면 펄스

화면 전체 테두리가 4회 반짝이며 알려줍니다. 어떤 탭에 있든 보입니다.

BUY = 초록 펄스 · SELL = 빨강 펄스

화면 분할 모드에서도 작동 — 다른 앱 사용 중에도 눈에 띕니다.

7 자주 묻는 질문

다른 탭에 있어도 알림이 오나요?

네, 브라우저가 열려있고 ORACLE 탭이 활성 상태면 어떤 탭(추천기/분석기/감독관 등)에 있어도 알림이 옵니다.

다른 앱으로 전환하면요?

모바일에서 다른 앱으로 전환하면 백그라운드 제한으로 스캔이 지연됩니다. 화면 분할 모드에서는 정상 작동합니다.

분석기에서 다른 종목 분석 중이면 충돌하나요?

아니요, 워치리스트 스캔은 분석기와 독립적으로 작동합니다. 동시에 사용해도 안전합니다.

API 제한에 걸리나요?

코인은 Upbit/Binance, 주식은 Yahoo Finance를 사용하므로 한투 API 제한과 무관합니다. 종목 간 0.8초 간격을 두어 안전합니다.
