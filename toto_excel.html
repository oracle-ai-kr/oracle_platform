📊 엑셀 데이터 수집 가이드

TOTO SIGNAL PRO에 업로드할 엑셀 파일 다운로드 방법

📋 왜 엑셀이 필요한가?

TOTO SIGNAL PRO는 두 가지 데이터 모드를 지원합니다.

1
🌐 실시간 API 모드
축구 7개 리그(K리그1/2, EPL, 분데스리가, 라리가, 세리에A, 리그앙)는 API로 자동 수신됩니다. 별도 작업 불필요.
2
📊 엑셀 업로드 모드
야구(KBO), 농구(KBL), 배구(V리그) 및 API 콜 절약이 필요할 때, 공식 사이트에서 엑셀을 다운받아 업로드합니다.

🎯 엑셀에 필요한 컬럼

아래 컬럼이 포함된 엑셀이면 자동 인식됩니다. 정확한 컬럼명이 아니어도 유사하면 자동 매칭됩니다.

💡 팀명만 있으면 기본 분석이 가능합니다. 승/무/패/득점/실점이 있을수록 정확도가 올라갑니다.

⚽ K리그 (K리그1 / K리그2)

✅ K리그는 API 모드로도 지원되지만, API 콜 절약을 위해 엑셀 업로드도 가능합니다.

📥 방법 1: K리그 데이터 포털 (추천)

💡 K리그 공식 사이트(kleague.com)의 기록실 직접 URL은 404가 뜹니다. 대신 데이터 포털을 이용하세요. 로그인 없이 이용 가능합니다.
1
K리그 데이터 포털 접속
로그인 없이 팀 순위, 기록 등 모든 데이터를 열람할 수 있는 공식 포털입니다.
🔗 data.kleague.com
📋 복사 ↗ 바로가기
2
팀 순위 확인
포털에서 K리그1 또는 K리그2 선택 → 순위 테이블 확인
3
표 복사 → 엑셀 저장
PC: 순위 테이블 전체 드래그 → Ctrl+C → 엑셀에 Ctrl+V → .xlsx 저장
모바일: 표 길게 눌러 선택 → 복사 → 스프레드시트 앱에 붙여넣기 → 엑셀로 저장

📥 방법 2: kleague.com 홈에서 진입

1
K리그 공식 홈페이지 접속
홈에서 시작합니다. (기록실 직접 URL은 404 에러)
🔗 kleague.com
📋 복사 ↗ 바로가기
2
메뉴에서 기록실 찾기
상단 햄버거 메뉴(☰) → 기록/순위 또는 기록실 메뉴 탐색 → 팀 기록 페이지로 이동
3
표 복사 → 엑셀 저장
순위 테이블이 보이면 전체 선택 → 복사 → 엑셀 붙여넣기 → .xlsx 저장
⚠️ K리그 사이트는 시즌 중에만 최신 기록이 업데이트됩니다. 2026 시즌은 3월 개막이니 개막 후 데이터를 확인하세요.

⚽ EPL (프리미어리그)

✅ EPL은 API 모드 테스트 완료. 엑셀은 API 콜 절약용 백업입니다.

📥 다운로드 방법 (FBref 이용)

1
FBref 사이트 접속
무료 축구 통계 사이트. 로그인 불필요.
🔗 fbref.com/en/comps/9/Premier-League-Stats
📋 복사 ↗ 바로가기
2
순위 테이블 찾기
페이지 상단의 Regular season 테이블이 순위표입니다.
3
CSV 또는 엑셀 내보내기
테이블 위에 Share & Export 드롭다운 → Get table as CSV (for Excel) 클릭 → 텍스트가 나오면 전체선택 → 복사 → 엑셀에 붙여넣기 → .xlsx 저장
💡 FBref은 분데스리가, 라리가, 세리에A, 리그앙도 지원합니다. URL의 /9/ 부분만 바꾸면 됩니다: 분데스리가 /20/ · 라리가 /12/ · 세리에A /11/ · 리그앙 /13/

💡 영어 컬럼명(Squad, W, D, L, GF, GA)도 TOTO에서 자동 인식됩니다.

⚾ KBO (한국 프로야구)

📥 다운로드 방법

1
KBO 공식 사이트 접속
기록 페이지로 이동합니다.
🔗 koreabaseball.com/Record/TeamRank/TeamRankDaily.aspx
📋 복사 ↗ 바로가기
2
팀 순위 페이지 확인
상단 메뉴 기록 → 팀 순위. 현재 시즌 순위표가 표시됩니다.
3
표 복사 → 엑셀 저장
KBO 사이트에는 직접 엑셀 다운로드 버튼이 없는 경우가 많습니다.
방법 A (PC): 표 전체 드래그 선택 → Ctrl+C → 엑셀 열기 → Ctrl+V → .xlsx 저장
방법 B (모바일): 표를 길게 눌러 선택 → 복사 → 메모장이나 스프레드시트 앱에 붙여넣기 → 엑셀로 저장
⚠️ KBO 사이트는 시즌(3월~10월) 중에만 실시간 순위가 업데이트됩니다.

🏀 KBL (한국 프로농구)

💡 KBL 사이트는 기록실 직접 URL이 404입니다. 홈에서 진입하면 바로 팀 순위가 보입니다.

📥 다운로드 방법

1
KBL 공식 홈페이지 접속
홈페이지에 접속하면 바로 경기 일정과 팀 순위 테이블이 보입니다.
🔗 kbl.or.kr
📋 복사 ↗ 바로가기
2
홈 화면 아래로 스크롤
홈 화면을 아래로 스크롤하면 팀 순위 테이블이 나옵니다. 컬럼: 순위 / 팀명 / 승 / 패 / 승률 / 승차
3
표 복사 → 엑셀 저장
PC: 순위 테이블 전체 드래그 → Ctrl+C → 엑셀에 Ctrl+V → .xlsx 저장
모바일: 표 영역 길게 눌러 선택 → 복사 → 스프레드시트 앱에 붙여넣기 → 엑셀로 저장

🔄 대안: 네이버 스포츠

🔗 sports.news.naver.com/basketball/record/index
📋 복사 ↗ 바로가기
💡
네이버 스포츠 농구 기록실
네이버 스포츠 → KBL → 순위 페이지에서도 동일한 순위표를 복사할 수 있습니다.
⚠️ KBL 시즌은 10월~4월입니다. 비시즌에는 이전 시즌 데이터만 제공됩니다.

🏐 V리그 (한국 프로배구)

💡 KOVO 사이트는 기록실 직접 URL이 404입니다. 홈에서 하단 "기록" 탭을 이용하세요.

📥 방법 1: KOVO 홈에서 진입

1
KOVO 공식 홈페이지 접속
홈페이지에 접속합니다.
🔗 kovo.co.kr
📋 복사 ↗ 바로가기
2
하단 "기록" 탭 선택
홈 화면 하단 네비게이션에서 🏆 기록 탭을 선택합니다. (경기 / 기록 / 시트 / 매장 / 내 페이지)
3
팀 기록 페이지에서 순위 확인
기록 탭 내에서 팀 기록 또는 팀 순위를 찾아 순위 테이블을 확인합니다.
4
표 복사 → 엑셀 저장
PC: 순위 테이블 전체 드래그 → Ctrl+C → 엑셀에 Ctrl+V → .xlsx 저장
모바일: 표 영역 길게 눌러 선택 → 복사 → 스프레드시트 앱에 붙여넣기 → 엑셀로 저장

📥 방법 2: KOVO 팀 기록 직접 URL 시도

🔗 kovo.co.kr/KOVO/stats/team-record
📋 복사 ↗ 바로가기
⚠️ 위 URL이 안 될 경우 홈(kovo.co.kr)에서 하단 "기록" 탭으로 진입하세요.

🔄 대안: 네이버 / 다음 스포츠

🔗 sports.daum.net/record/vl (다음 스포츠 배구 순위)
📋 복사 ↗ 바로가기
⚠️ V리그 시즌은 10월~4월입니다. 시즌 종료 후에는 최종 순위만 남아있습니다.

📤 TOTO에 업로드하기

1
TOTO SIGNAL PRO 열기
ORACLE 플랫폼에서 TOTO SIGNAL PRO에 진입합니다.
2
📊 엑셀 업로드 버튼 선택
상단의 [📊 엑셀 업로드] 버튼을 누르면 파일 업로드 영역이 나타납니다.
3
파일 선택
업로드 영역을 클릭 → 다운받은 .xlsx 또는 .csv 파일 선택. 파싱이 완료되면 "✅ N팀 데이터 로드 완료" 토스트가 표시됩니다.
4
팀 선택 → 분석
홈/원정팀 드롭다운에 엑셀의 팀 목록이 반영됩니다. 검색창에 팀명을 타이핑하여 빠르게 찾을 수 있습니다.
✅ 업로드한 데이터는 브라우저 메모리에만 존재합니다. 페이지를 새로고침하면 초기화되므로, 필요할 때마다 다시 업로드하세요.

🚨 파싱 실패 시 체크리스트

❌
컬럼 인식 실패
"팀명 컬럼을 찾을 수 없습니다" → 첫 번째 행이 헤더인지 확인. 헤더에 "팀", "팀명", "team", "구단" 등의 키워드가 포함되어야 합니다.
❌
파일 형식 오류
.xlsx, .xls, .csv 형식만 지원됩니다. 구글 시트의 경우 파일 → 다운로드 → .xlsx로 내보내세요.
❌
빈 데이터
엑셀의 첫 번째 시트에 데이터가 있어야 합니다. 여러 시트가 있으면 첫 번째 시트만 읽힙니다.
