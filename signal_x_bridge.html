📦 배포 파일 가이드
AI 산출물 2개 모두 배포:
✓ signal_x.json → stocks/ 폴더
✓ market_report.json → market/ 폴더
+ daily/ 폴더에 오늘 날짜 스냅샷도 추가 권장
🔄 SX Data Manager 파일명 자동 변환
stocks/ → 005380_signal_x.json → 005380.KS.json
market/ → 아무파일명 → latest.json
ranking/ → 아무파일명 → latest.json
daily/ → 날짜 자동 감지 또는 오늘 날짜
파일명 신경 안 쓰고 폴더만 선택하면 됨
💡 팁:
· txt 버튼으로 각 소스를 파일로 내보내기 가능 (다른 기기 수동 업로드)
· 결과 탭에서 미리보기 이상하면 AI에게 재생성 요청
· 소스 1,2는 "질문"을 저장, 소스 3은 "데이터"를 저장
· AI가 3소스를 한 맥락에서 처리 → signal_x.json + market_report.json 2개 생성
