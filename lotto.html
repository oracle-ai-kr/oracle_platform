📘 전문가 매뉴얼 (로또 6/45)

        
      

      

        
1) 엔진 개요

        
    
          
  • 필터/가중/점수화 옵션을 조합해서 후보를 압축한 뒤 상위 조합을 출력합니다.
    • 
          
  • 히트맵·반자동·카드/게임은 “입력 보조”이며 최종 생성 로직은 필터/샘플링/점수화 설정에 의해 결정됩니다.
    • 
        


        
2) 추천 운용(빠른 루틴)

        
    
          
  1. 데이터 불러오기 → 완료 표시 확인
    2. 
          
  2. 필터 기본 사용(추천) 버튼으로 기본 셋업
    3. 
          
  3. 필요하면 히트맵에서 1~3개만 반자동으로 보조 입력
    4. 
          
  4. 번호 생성 → 검증 대시보드 점수/범위 확인
    5. 
        


        
3) 옵션 가이드

        
    
          
  • 점수화 사용: 후보를 점수로 랭킹화(OFF=랜덤성↑).
    • 
          
  • 가중 샘플링: 특정 패턴/분포를 더 자주 뽑도록 샘플링 편향을 부여.
    • 
          
  • PRO 디버그: 로그/진단 표시(일반 사용자는 OFF 권장).
    • 
        


        
4) 주의

        
    
          
  • 로또는 확률 게임입니다. 과몰입/무리한 구매를 피하세요.
    • 
          
  • 설정이 과도하면 후보가 너무 줄어 결과가 단조로워질 수 있습니다.
