01
ORACLE 플랫폼이란?

ORACLE은 게임, 운세, AI 분석 서비스를 하나의 플랫폼에서 이용할 수 있는 통합 서비스입니다.

모든 서비스는 포인트(P)로 운영되며, 매일 충전소에서 무료로 포인트를 수급할 수 있습니다. 별도 결제나 회원가입 없이 바로 이용 가능합니다.

📌 KIS API 키란?

한국투자증권에서 제공하는 OpenAPI 인증 키입니다. 이 키가 있으면 코스피/코스닥 종목의 실시간 시세와 캔들 데이터를 가져올 수 있습니다. 무료로 발급받을 수 있으며, 한국투자증권 계좌가 필요합니다.

🏦 STEP 1. 한국투자증권 계좌 개설

이미 계좌가 있다면 이 단계를 건너뛰세요.

→ 한국투자증권 홈페이지 접속

→ 비대면 계좌 개설 (모바일 앱 또는 홈페이지에서 가능)

→ 신분증 + 본인 명의 휴대폰 필요

→ 개설 완료까지 약 1~2 영업일 소요

🔐 STEP 2. KIS Developers 가입

→ KIS Developers 포털 접속

→ 우측 상단 "회원가입" 클릭

→ 한국투자증권 계좌번호 + 본인인증으로 가입

→ 가입 완료 후 로그인

🔧 STEP 3. API 앱 등록 및 키 발급

→ 로그인 후 상단 메뉴 "API 신청" → "앱 등록"

→ 앱 이름: 자유 입력 (예: "ORACLE분석")

→ 서비스 유형: "개인" 선택

→ 계좌번호 선택 → "등록" 클릭

→ 등록 완료 시 App Key와 App Secret이 발급됩니다

📲 STEP 4. ORACLE에 키 입력

→ ORACLE 플랫폼 → "주식/ETF 분석기" 입장

→ 상단 "설정" 탭 클릭

→ "한국투자증권 API 키" 섹션에 App Key, App Secret 입력

→ "저장" 클릭 → 한국 주식 분석 사용 가능!

💡 모의투자 계좌도 가능합니다. 실제 매매를 하지 않아도, 모의투자 계좌로 API 키를 발급받아 데이터 조회에 사용할 수 있습니다.
ℹ️ KIS 키 없이도 해외 주식(미국, 유럽, 일본 등) 분석은 정상 작동합니다. 한국 주식(코스피/코스닥)만 KIS 키가 필요합니다.
🤖 자동으로 제공되는 데이터
  • AUTODART 재무 데이터 — 한국 주식의 기업개황, 재무제표, 공시 정보가 자동 수집됩니다
  • AUTO바이낸스 파생 데이터 — 펀딩비, 미결제약정, 롱숏비율이 자동 연동됩니다
  • AUTO업비트 김치 프리미엄 — 원화 가격과 해외 가격 차이가 자동 계산됩니다
  • AUTO공포탐욕지수 — 시장 심리 지표가 실시간 반영됩니다

분석 도구 이용 안내
📊 주식/ETF 분석기

사용 방법: 티커 입력 (예: AAPL, TSLA, 005930.KS) → 분석 시작

탭 구성:

탭기능
추천기즐겨찾기 시그널 목록, 시총 상위 스캔, 스마트 필터 (골든크로스, RSI 과매도, 거래량 급증 등)
분석기종합 점수(BUY/SELL/HOLD), 4Way 분석, 지표별 신호 12개, 매매 레벨(목표가+손절가+ETA), 재무 밸류에이션
감독관분석기 판정 교차 검증, 위험 요소 감지 시 자동 HOLD 전환, 종합 리포트(현재 상태/핵심 이유/위험 해설/BUY 전환 조건/레벨 가이드)
설정타임프레임(60분/일/주/월), 스코어링 모드(보수적/일반/공격적), KIS API 키 설정

점수 기준: 62점 이상 = BUY, 38점 이하 = SELL, 39~61점 = HOLD

⚠️ 점수는 RSI, MACD, 스토캐스틱, CCI, ADX, OBV 등 기술적 지표를 규칙 기반으로 합산한 것입니다.
₿ 코인 분석기

주식 분석기와 동일한 기술적 분석에 코인 전용 데이터가 추가됩니다.

코인 전용 카드내용
파생 데이터펀딩비, 미결제약정, 롱숏비율 — 바이낸스 선물 시장 데이터
김치 프리미엄업비트(KRW) vs 바이낸스(USDT) 가격 차이 — 5% 이상이면 과열 주의
공포탐욕지수시장 심리 0~100 — 20 이하 극단적 공포, 80 이상 극단적 탐욕

데이터 출처: 바이낸스(주 데이터), 업비트(원화 가격), CoinGecko(도미넌스)

🔬 시그널랩 AI 분석

AI(Claude, chatGPT 등)에게 정확한 분석을 요청하기 위한 데이터 자료 준비 도구입니다.

사용 순서:

1. 종목 티커 입력 + 타임프레임 선택 → "분석" 클릭

2. 3가지 출력물 생성:

출력물내용용도
📸 차트 이미지캔들+이동평균+볼린저밴드 캡처시각적 패턴 분석
📝 TEXTRSI, MACD, 추세, 변동성 등 수치 텍스트수치 기반 분석
📊 JSON구조화된 전체 데이터정밀 데이터 분석

3. 세 가지를 AI에게 함께 전달하면 가장 정확한 분석을 받을 수 있습니다.

💡 추천 프롬프트: "이 종목의 차트와 데이터를 분석해주세요. 매수/매도 판단과 근거, 목표가/손절가를 알려주세요."

⚽ 토토 예측

실제 경기 데이터 기반의 축구 승부 예측 서비스입니다.

예측 요소: 리그 순위, 최근 폼(5경기), 상대전적(H2H), 홈/원정 승률, 이동거리 피로도, 더비 보너스, 시즌 단계 가중치

신뢰도: 75%↑ 높음 (전력 격차 명확) / 55~74% 보통 / 55%↓ 낮음 (박빙)

⚠️ 예측은 통계 기반 참고 자료이며, 실제 경기 결과를 보장하지 않습니다.

05
데이터 저장 안내

ORACLE은 서버에 개인정보를 저장하지 않습니다.

모든 데이터(포인트, 설정, 분석 결과, KIS 키 등)는 브라우저의 localStorage에만 저장됩니다.

  • 📱기기별 독립 — 다른 기기에서 접속하면 포인트 0부터 시작
  • 🗑️브라우저 데이터 삭제 시 모든 정보 초기화
  • 🔒KIS API 키는 본인의 브라우저에만 저장, 외부 전송 없음
  • 🌐분석 요청 시 데이터는 공개 API 서버로만 전송 (Yahoo Finance, 바이낸스 등)
06
면책 및 주의사항
⚠️ 투자 관련 면책 고지

• 각종 분석기의 판단 스코어는 단순 규칙 기반 합산이며, 통계적 데이터를 기반합니다.
• BUY/SELL/HOLD 판정은 기술적 지표의 기계적 종합 결과입니다.
• 본 서비스의 분석 결과는 참고 자료일 뿐이며, 투자 권유가 아닙니다.
• 최종 투자 판단은 본 데이터를 종합적으로 판단하여 본인의 책임 하에 결정하시기 바랍니다.
• 투자로 인한 손실에 대해 ORACLE 플랫폼은 어떠한 책임도 지지 않습니다.
⚽ 토토 예측 관련

• 경기 예측은 통계 기반 참고 자료이며, 실제 결과를 보장하지 않습니다.
• 스포츠 베팅은 관련 법규를 준수하시기 바랍니다.
