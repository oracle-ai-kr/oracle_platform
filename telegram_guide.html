ORACLE 시그널을 실시간으로 텔레그램에서 받으세요
0 어떻게 작동하나요?
ORACLE이 매수/매도 시그널을 감지하면, 텔레그램 봇이 본인의 텔레그램으로 알림을 보냅니다.

다른 사용자에게는 전송되지 않습니다 — Chat ID로 개인 식별되기 때문입니다.
봇 1개 × Chat ID 각자 다름 = 각자 본인에게만 도착
1 텔레그램 설치
앱 다운로드
이미 설치되어 있다면 이 단계를 건너뛰세요.
telegram.org/dl 에서 다운로드하거나
앱스토어/플레이스토어에서 Telegram 검색
회원가입

봇을 찾으면 터치 → 하단의 시작(START) 버튼을 누르세요.

4 ORACLE에 Chat ID 입력
설정 열기
ORACLE 분석기(Stock Signal / Coin Signal)에서
워치리스트 → 알림 설정 또는 설정 탭을 엽니다.
Chat ID 입력
텔레그램 Chat ID 입력란에 3단계에서 확인한 숫자를 입력하고 저장을 누르세요.
테스트 전송
🔔 테스트 알림 버튼을 눌러 텔레그램에 메시지가 도착하는지 확인하세요.
설정 완료 후 워치리스트에 종목을 추가하면, 시그널 변동 시 자동으로 텔레그램 알림이 발송됩니다.

❓ 자주 묻는 질문
다른 사람도 내 알림을 볼 수 있나요? ▼
아니요. Chat ID는 본인의 텔레그램 계정에만 연결되며, 다른 사용자의 알림과 완전히 분리됩니다. 봇은 하나지만, 메시지는 각자의 Chat ID로만 전송됩니다.
Chat ID가 유출되면 위험한가요? ▼
Chat ID 자체로는 계정 해킹이 불가능합니다. 하지만 스팸 메시지를 받을 수 있으므로, 불필요하게 공유하지 않는 것을 권장합니다.
알림이 안 오면 어떻게 하나요? ▼
① Chat ID가 정확한지 확인
② ORACLE 봇에게 /start를 다시 보내기
③ 텔레그램 알림 설정이 켜져있는지 확인
④ ORACLE 설정에서 테스트 알림 재시도
Chat ID를 변경할 수 있나요? ▼
Chat ID는 텔레그램 계정에 고정된 값이라 변경할 수 없습니다. 다른 계정을 사용하고 싶다면 해당 계정의 Chat ID를 새로 확인하세요.
무료인가요? ▼
네. 텔레그램 앱, ORACLE 봇, 알림 서비스 모두 무료입니다.
