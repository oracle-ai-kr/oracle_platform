📘 전문가 매뉴얼 (연금복권 720+)

        
      

      

        
1) 엔진 개요

        
    
          
  • 로또 엔진 UI/구조를 연금 규칙에 맞게 변환한 버전입니다.
    • 
          
  • 필터/가중/점수화로 후보를 압축하고 상위 결과를 생성합니다.
    • 
        


        
2) 추천 운용(빠른 루틴)

        
    
          
  1. 바로 사용 가능 또는 필터 기본 사용(추천)으로 시작
    2. 
          
  2. 필요 시 히트맵/카드로 1~3자리만 보조 입력(중복은 자동 방지)
    3. 
          
  3. 번호 생성 → 대시보드 점수/범위 확인
    4. 
        


        
3) 옵션 가이드

        
    
          
  • 점수화 사용: 후보를 점수로 랭킹화(OFF=랜덤성↑).
    • 
          
  • 가중 샘플링: 특정 분포를 더 자주 선택하도록 편향을 부여.
    • 
          
  • PRO 디버그: 로그/진단 표시(일반 사용자는 OFF 권장).
    • 
        


        
4) 주의

        
    
          
  • 연금복권도 확률 게임입니다. 과몰입/무리한 구매를 피하세요.
