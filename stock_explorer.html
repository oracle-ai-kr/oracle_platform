⚽ 엑셀 데이터 수집 가이드

TOTO SIGNAL PRO에 업로드할 엑셀 파일 다운로드 방법

📋 왜 엑셀이 필요한가?

TOTO SIGNAL PRO는 두 가지 데이터 모드를 지원합니다.

1
🌐 실시간 API — api-football.com 연동 (축구 전용, 무료 100콜/일)
2
📊 엑셀 업로드 — 모든 종목 지원 (야구/농구/배구 등)
💡 API가 지원하지 않는 종목(KBO, KBL, V리그 등)은 엑셀 모드로 분석할 수 있습니다.

📊 엑셀 필수 컬럼

팀명, 순위, 승, 무(없으면 0), 패, 득점, 실점 — 이 7개 컬럼이 있으면 어떤 종목이든 분석 가능합니다.

⚽ K리그 데이터 수집

1
아래 사이트에서 K리그1/K리그2 순위표를 확인합니다.
https://www.kleague.com/record/teamRank.do
🔗 K리그 사이트 바로가기
2
순위표 전체 선택 → 복사(Ctrl+C) → 엑셀에 붙여넣기. 또는 스크린샷 보고 직접 입력.
3
필수 컬럼: 팀명, 순위, 승, 무, 패, 득점, 실점
💡 K리그는 API(리그ID 292/293)로도 실시간 데이터를 받을 수 있습니다. 엑셀은 API 장애 시 백업용.
⚠️ 사이트에서 표 복사가 안 되면? → 순위표 스크린샷을 찍고 수동으로 엑셀에 입력하세요. 팀 수가 12개라 금방 끝납니다.

⚽ EPL 데이터 수집

1
EPL 공식 사이트에서 순위표를 확인합니다.
https://www.premierleague.com/tables
🔗 EPL 사이트 바로가기
2
순위표 데이터를 엑셀로 정리합니다.
💡 EPL은 API(리그ID 39)로 자동 연동됩니다. 엑셀은 백업/오프라인용.

⚾ KBO 데이터 수집

1
KBO 공식 사이트에서 팀 순위를 확인합니다.
https://www.koreabaseball.com/Record/TeamRank/TeamRankDaily.aspx
🔗 KBO 사이트 바로가기
2
순위표를 길게 눌러 선택 → 복사 → 엑셀에 붙여넣기. 표 복사가 안 되면 스크린샷 보고 수동 입력.
3
컬럼 정리: 팀명, 순위, 승, 패, 득점, 실점. 야구는 무승부가 거의 없으니 무 컬럼은 0으로.
⚾ KBO는 API 미지원 — 엑셀 업로드 전용입니다. 10개 팀이라 수동 입력도 1분이면 됩니다.

🏀 KBL 데이터 수집

1
KBL 공식 사이트에서 팀 순위를 확인합니다.
https://www.kbl.or.kr/record/team-rank
🔗 KBL 사이트 바로가기
2
순위표를 엑셀로 정리합니다. 농구는 무승부 없으니 무 컬럼은 0으로.
🏀 KBL은 API 미지원 — 엑셀 업로드 전용. 10개 팀, 수동 입력 1분.
⚠️ KBL 사이트가 모바일에서 표 복사 불가할 수 있습니다 → PC에서 접속하거나 스크린샷 후 수동 입력하세요.

🏐 V리그 데이터 수집

1
KOVO 공식 사이트에서 팀 순위를 확인합니다.
https://www.kovo.co.kr/game/v-league/11110_team-rank.asp
🔗 V리그 사이트 바로가기
2
남자부/여자부 각각 순위표를 엑셀로 정리합니다. 무승부 없으면 0으로.
🏐 V리그는 API 미지원 — 엑셀 업로드 전용. 각 7개 팀.
⚠️ KOVO 사이트가 모바일에서 접근이 어려울 수 있습니다 → PC 접속 또는 네이버 "V리그 순위" 검색 후 데이터 입력.

📤 TOTO에 업로드하는 방법

1
위 가이드대로 엑셀 파일(.xlsx)을 준비합니다. 필수 컬럼: 팀명, 순위, 승, 무, 패, 득점, 실점
2
TOTO SIGNAL PRO에서 상단 [📊 엑셀 업로드] 버튼을 누릅니다.
3
준비한 엑셀 파일을 선택하면 자동으로 컬럼을 감지하고 팀 목록이 로드됩니다.
4
홈/원정 팀을 선택하고 [분석 실행]을 누르면 17개 엔진이 예측 결과를 출력합니다.
💡 컬럼명이 정확히 일치하지 않아도 자동 매칭을 시도합니다 (예: "팀" → "팀명", "점수" → "득점"). 실패 시 컬럼명을 확인하세요.
💡 엑셀 모드에서는 API 콜을 소모하지 않습니다. 무제한 분석 가능!
